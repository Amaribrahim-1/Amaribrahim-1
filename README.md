My competitive programming background gave me something most developers lack: a genuine problem-solving mindset trained on real algorithmic challenges. I apply that same rigor to every layer of my frontend work — from React render cycles to component architecture to API design.

I believe in:
- **Depth over breadth** — master the fundamentals, frameworks become easy
- **Shipping over perfecting** — real feedback beats imagined edge cases
- **Performance as a feature** — memoization and lazy loading aren't optional
